# 🚀 快速测试指南

> 下午2点睡醒后，按此指南测试  
> 预计时间：30分钟

---

## 📋 测试顺序

### 第一步：确认服务运行（1分钟）

```bash
# 检查服务状态
./service.sh status
```

浏览器访问：http://localhost:8000/health

✅ **预期：** 显示 `{"status": "ok"}`

---

### 第二步：测试客户管理（5分钟）

1. 访问：http://localhost:8000/customers
2. **添加客户：**
   - 点击 "+ 添加客户"
   - 填写：姓名=`测试客户`，手机号=`13912345678`，备注=`手动测试`
   - 点击保存
3. **编辑客户：**
   - 点击刚添加客户的"编辑"按钮
   - 修改备注为：`已更新`
   - 点击保存
4. **删除客户：**
   - 点击"删除"按钮
   - 确认删除

✅ **预期：** 客户可以正常增删改

---

### 第三步：测试文本客服（10分钟）

1. 访问：http://localhost:8000/chat
2. **发送消息：**
   - 输入：`你好`
   - 等待5-6秒（百炼API较慢）
   - 查看AI回复
3. **测试FAQ：**
   - 输入：`洗牙多少钱？`
   - 等待回复
   - 验证回答准确性
4. **测试多轮对话：**
   - 继续输入：`那补牙呢？`
   - 验证上下文理解

✅ **预期：** AI回复正常，问答准确

---

### 第四步：测试AI外呼（10分钟）

1. 访问：http://localhost:8000/outbound
2. **发起外呼：**
   - 输入手机号：`your-phone-number`（张三，白名单号码）
   - 点击"拨打"
   - 等待拨打结果
3. **验证通话记录：**
   - 刷新页面
   - 查看通话记录表格
   - 应该看到新增的通话记录

✅ **预期：** 外呼成功，通话记录自动保存

---

### 第五步：测试Webhook（2分钟）

打开终端，执行：

```bash
curl -X POST http://localhost:8000/api/webhook/ccc/call-ended \
  -H "Content-Type: application/json" \
  -d '{
    "call_id": "test-manual-001",
    "callee": "13800138001",
    "status": "answered",
    "duration": 120
  }'
```

✅ **预期：** 返回 `{"success": true, "message": "通话记录已保存"}`

---

### 第六步：验证数据关联（2分钟）

1. 访问：http://localhost:8000/customers
2. 找到 "张三"（your-phone-number）
3. 查看其通话记录

✅ **预期：** 显示张三的所有通话记录

---

## 🐛 快速排错

### 服务未运行？
```bash
./service.sh start
```

### 外呼失败？
- 使用白名单号码：your-phone-number
- 检查CCC配置

### AI回复很慢？
- 正常现象（5-6秒）
- 耐心等待

### 查看日志？
```bash
./service.sh logs
```
