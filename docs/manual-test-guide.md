## 🐛 常见问题及解决方案

### 问题1：页面无法访问

**现象：** 浏览器显示"无法访问此网站"

**解决方案：**
```bash
# 检查服务状态
./service.sh status

# 如果未运行，启动服务
./service.sh start

# 查看日志
./service.sh logs
```

---

### 问题2：客户添加失败

**现象：** 点击保存后无反应或报错

**可能原因：**
- 手机号已存在
- 手机号格式不正确

**解决方案：**
- 使用不同的手机号
- 确保手机号为11位数字

---

### 问题3：AI回复很慢

**现象：** 发送消息后等待很久才回复

**原因：** 百炼API响应慢（正常5-6秒）

**解决方案：**
- 耐心等待
- 已优化loading动画

---

### 问题4：外呼失败

**现象：** 点击拨打后报错

**可能原因：**
- 号码不在CCC白名单
- CCC配置错误
- API凭证问题

**解决方案：**
- 使用白名单号码：13950481396、13800138001、13800138002
- 检查.env配置
- 查看日志排查原因

---

### 问题5：通话记录未保存

**现象：** 外呼后看不到通话记录

**可能原因：**
- 外呼未成功
- 数据库连接问题

**解决方案：**
```bash
# 检查数据库
./venv/bin/python -c "from backend.models.database import SessionLocal, CallRecord; db = SessionLocal(); print(f'通话记录数: {db.query(CallRecord).count()}')"

# 查看日志
./service.sh logs | grep -i "call"
```
