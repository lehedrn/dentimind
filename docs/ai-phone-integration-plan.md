# AI电话语音对话实现方案

> 版本：v1.0  
> 日期：2026-09-20  
> 目标：实现AI自动接听和AI自动外呼

---

## 一、需求概述

### 1.1 核心功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| **AI接听** | 客户呼入 → AI自动接听 → 语音对话 → 记录保存 | P0 |
| **AI外呼** | 系统外呼 → 客户接听 → AI语音对话 → 记录保存 | P0 |
| **转人工** | AI无法处理 → 转接人工客服 | P1 |
| **智能路由** | 根据客户需求分配到对应AI场景 | P2 |

### 1.2 业务场景

#### 场景1: AI接听（呼入）
```
客户拨打医院电话
    ↓
AI自动接听："您好，这里是XX口腔医院，我是AI客服小雅，请问有什么可以帮您？"
    ↓
客户说话："我想咨询一下洗牙多少钱？"
    ↓
ASR识别 → 文字 → 百炼AI生成回复
    ↓
TTS播放："洗牙的价格一般在200-500元之间，具体价格需要..."
    ↓
继续对话...
    ↓
通话结束 → 保存记录
```

#### 场景2: AI外呼（呼出）
```
系统自动拨打客户电话
    ↓
客户接听
    ↓
AI播放："您好，这里是XX口腔医院，我是AI客服小雅。您上周在我们这里做了洗牙，现在感觉怎么样？"
    ↓
客户回答："感觉挺好的，牙齿不敏感了。"
    ↓
AI继续对话...
    ↓
通话结束 → 保存记录
```

#### 技术栈
| 组件 | 阿里云产品 | 作用 | 费用 |

- ❌ 需要开发实时对话引擎
- ❌ 延迟较高（ASR + AI + TTS = 2-3秒）
- ❌ 费用较高（ASR/TTS按秒计费）

- **ASR集成**: 3-4天
- **TTS集成**: 2-3天
- **对话引擎**: 5-7天
- **电话控制**: 2-3天
- **测试优化**: 3-5天

### 4.3 关键代码示例

#### 4.3.1 AI外呼
```python
# backend/services/ccc_ai.py
from alibabacloud_ccc20200701 import models

class CCCAIService:
    async def make_ai_call(self, phone: str, scenario: str):
        """
        发起AI外呼
        
        Args:
            phone: 客户手机号
            scenario: 对话场景（如：回访、预约提醒）
        """
        # 1. 调用CCC MakeCall API，指定AI坐席
        request = models.MakeCallRequest(
            instance_id=self.instance_id,
            caller_number=self.caller_number,
            callee_number=phone,
            # 关键：指定AI坐席
            agent_type="AI",
            ai_scenario=scenario,  # 对话场景
        )
        
        response = self.client.make_call(request)
        
        # 2. 保存通话记录
        record = CallRecord(
            id=str(uuid.uuid4()),
            customer_id=self._get_or_create_customer(phone),
            direction='outbound',
            callee_number=phone,
            call_id=response.body.call_id,
            status='initiated',
            call_type='ai_outbound'  # 标记为AI外呼
        )
        db.add(record)
        db.commit()
        
        return {
            "call_id": response.body.call_id,
            "status": "initiated"
        }
```

#### 4.3.2 AI接听配置
```python
# 在CCC控制台配置
# 1. 创建AI坐席

async def configure_ai_agent(self):
    """配置AI坐席参数"""
    request = models.CreateAgentRequest(
        instance_id=self.instance_id,
        agent_type="AI",
        agent_name="口腔医院AI客服",
        # AI配置
        ai_config={
            "prompt": "你是XX口腔医院的AI客服助手...",
            "knowledge_base_id": "your-bailian-kb-id",
            "tts_voice": "xiaoyun",  # 语音角色
            "asr_language": "zh-CN",
        }
    )
    
    response = self.client.create_agent(request)
    return response.body.agent_id
```
