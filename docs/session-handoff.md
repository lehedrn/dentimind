## ⚠️ 注意事项

1. **虚拟环境**：使用 `./venv/bin/python` 运行Python脚本
2. **数据库路径**：使用绝对路径，避免工作目录问题
3. **CCC API字段**：使用下划线命名（如 `called_number`）
4. **百炼API**：使用智能体应用API，支持session_id多轮对话
5. **依赖版本**：dashscope 1.27.5, sqlalchemy 2.0.23
