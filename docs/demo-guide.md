### 第二部分：文本客服演示（5分钟）

**演示步骤：**

1. **打开聊天界面**（http://localhost:8000/chat）

2. **演示基础咨询**
   ```
   用户：你好，我想咨询一下种植牙
   AI：您好！我是口腔医院AI客服小雅...（展示专业回复）
   ```

3. **演示多轮对话**
   ```
   用户：多少钱？
   AI：种植牙的价格根据品牌和材质不同...（展示上下文理解）
   
   用户：有优惠吗？
   AI：目前我们有种植牙套餐优惠活动...（展示营销引导）
   ```

4. **演示专业知识**
   ```
   用户：种植牙疼不疼？
   AI：种植牙手术是在局部麻醉下进行的...（展示专业知识）
   ```

**讲解要点：**

> "大家可以看到，我们的AI客服具备以下特点：
> 
> 1. **专业性强** - 基于口腔医学知识库训练
> 2. **多轮对话** - 能理解上下文，自然流畅
> 3. **营销引导** - 适时推荐优惠活动，促进转化
> 4. **24小时在线** - 不遗漏任何客户咨询
> 
> 根据测试数据，AI客服可以处理80%以上的常见咨询，大幅降低人工客服压力。"

### 第三部分：客户管理演示（4分钟）

**演示步骤：**

1. **切换到客户管理页面**（http://localhost:8000/customers）

2. **展示客户列表**
   - 展示现有客户数据
   - 说明客户信息结构

3. **添加新客户**
   - 点击"+ 添加客户"
   - 填写客户信息（姓名、电话、备注）
   - 保存并展示成功提示

4. **查看客户详情**
   - 点击"查看"按钮
   - 展示客户详细信息

5. **查看通话记录**
   - 点击"通话记录"按钮
   - 展示该客户的历史通话
   - 播放录音（如果有）

**讲解要点：**

> "客户管理系统帮助医院实现：
> 
> 1. **客户信息集中管理** - 所有客户信息一目了然
> 2. **通话记录追踪** - 每次沟通都有记录可查
> 3. **录音回放** - 质量监控和培训素材
> 4. **数据分析基础** - 为精准营销提供数据支撑"

### 第四部分：电话外呼演示（5分钟）

**演示步骤：**


3. **查看通话记录**
   - 展示通话记录列表
   - 说明各字段含义（号码、类型、状态、时长、时间、录音）

4. **演示录音播放**（如果有录音）
   - 点击录音播放器
   - 播放通话录音

**讲解要点：**

> "电话外呼系统的应用场景：
> 
> 1. **术后回访** - 自动外呼术后患者，了解恢复情况
> 2. **预约提醒** - 提醒客户按时就诊
> 3. **满意度调查** - 收集客户反馈
> 4. **活动通知** - 推送优惠活动信息
> 
> 系统特点：
> - **自动化外呼** - 无需人工拨号，提高效率
> - **通话自动录音** - 所有通话自动录音存档
> - **记录可追溯** - 通话记录完整保存
> - **成本降低** - 减少人工外呼工作量

> **说明**：当前实现的是普通电话外呼功能，客户接听后由人工客服接听。未来可以升级为AI智能外呼，实现AI与客户直接对话。"
