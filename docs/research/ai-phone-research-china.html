核心结论

残酷现实

中国大陆所有主流云通信平台的电话外呼/接听服务，都要求企业实名认证。个人开发者身份（含个体工商户）无法直接开通阿里云语音服务、腾讯云呼叫中心、讯飞语音外呼等核心服务。

这不是技术限制，是法律合规要求：工信部规定电话外呼必须实名到企业，且需通过话术审核和备案。即使企业身份，个体工商户、自然人独资、个人独资公司也被排除（阿里云明确拒绝）。

可行路径

虽然直接打电话存在资质壁垒，但有三条可操作的路径：

1. 演示阶段：用 WebRTC + 开源框架搭建语音 AI Demo（无需电话线路，1-2天可完成）

2. 小规模验证：注册有限责任公司（~2周）+ 国际 SIP 号码过渡测试（~1天）

3. 正式部署：企业身份 + 合规服务商（阿里云/讯飞/容联云），3-4周可上线

合规红线 — 为什么个人不行

电话外呼在中国大陆受严格监管，核心法规和要求如下：

法规/要求 内容 影响
工信部 B24 呼叫中心许可证 全网需注册资本≥1000万；省内≥100万 个人和个体工商户无法申请
运营商反电信诈骗要求 每个语音号码必须实名到一个企业 号码不能登记在个人名下
话术审核 & 备案 外呼话术内容需提前审核并备案 个人无法完成此流程
《个人信息保护法》 外呼必须基于用户明确授权 需建立授权记录系统
《消费者权益保护法实施条例》第24条 未经消费者同意不得拨打商业性电话 违规面临行政处罚
特别注意

即使找到灰色渠道绕过监管，风险极高：运营商封号（已有企业单日80%号码被封）、行政处罚、甚至刑事责任。口腔医院场景属于正规商业行为，务必走合规路线。

合法获取资质的路径

  1. 注册有限责任公司（非自然人独资）— 费用 ~500-2000元，时间 1-2周。这是最基础的要求。
  2. 完成企业实名认证 — 在各云平台完成企业认证，通常 1-3 个工作日。
  3. 提交话术审核 — 准备口腔医院外呼话术（预约提醒、回访等），提交平台审核。
  4. 购买号码 & 线路 — 根据业务需求选择合适的号码类型。

SIP 软电话方案

演示可行性分析

用 SIP 软电话做演示在技术上完全可行，但在中国大陆场景有明确局限：

方案 可行性 优点 缺点
Voip.ms + 国际号码 推荐用于Demo 个人即可注册；API完善；支持SIP/WebRTC；$10起充 国际号码，中国大陆来电显示为境外号；对方需接国际长途

3CX IP PBX 仅内部测试 免费版可用；界面友好 同上，无PSTN接入

FreeSWITCH + AI 对接架构

SIP 软电话 → FreeSWITCH → WebSocket / ESL → AI Agent (Python)

FreeSWITCH通过Event Socket或WebSocket将实时音频流转发给AI处理模块

FreeSWITCH 可通过以下方式对接 AI：

  • mod_audio_fork — 将通话音频通过 WebSocket 实时转发给 AI 服务
  • SignalWire AI Agent — FreeSWITCH 官方 SignalWire 提供的 AI 集成方案
  • ESL (Event Socket Layer) — 通过编程接口控制通话并获取音频流

LiveKit — 最推荐的选择

为什么推荐 LiveKit：

  • 2025年原生支持SIP和电话号码，不再需要 Twilio 中间层
  • 开源 Python Agents 框架，与各种 LLM/ASR/TTS 无缝集成
  • 支持 WebRTC（浏览器演示）和 Telephony（真实电话）两种模式
  • 社区活跃，文档完善，迭代速度快（v1.0 → v1.5 仅一年）
  • 可部署到 LiveKit Cloud（免费tier）或自建
# LiveKit 快速启动示例（Python） pip install livekit-agents livekit-plugins-openai livekit-plugins-deepgram # 支持的外呼模式： # 1. WebRTC → 浏览器内语音对话（无需电话线路） # 2. SIP → 通过SIP trunk连接真实电话 # 3. Phone Numbers → LiveKit直接购买和管理电话号码

Vocode — 备选方案

Vocode 是一个成熟的开源 Python 框架，专门为语音 AI 设计：

  • 明确支持中文、日文、韩文等多语言电话通道
  • 支持 inbound 和 outbound 通话
  • 可对接 Twilio、Vonage 等电话服务商
  • 内置打断检测、话轮管理、静音处理等电话场景核心功能
  • 开源核心免费，但电话/模型/SIP等运营成本另计

推荐方案

推荐路径：分两阶段走

阶段一（Day 1-3）：用开源框架 + WebRTC 搭建 AI 语音 Demo，展示对话能力

阶段二（Week 2-4）：注册公司 + 对接合规电话线路，实现真实电话外呼/接听

阶段一：快速 Demo（无需企业资质）

浏览器 (WebRTC) → LiveKit Server → AI Agent (Python) → LLM + TTS + ASR

用户通过浏览器直接与AI语音对话，无需电话线路

具体技术栈：

  • 语音AI框架：LiveKit Agents（首选）或 Vocode
  • ASR（语音识别）：FunASR（本地部署，免费，中文优秀）或 讯飞基础版（个人可用）
  • TTS（语音合成）：Edge TTS（免费）或 CosyVoice（阿里开源，本地部署）
  • LLM（对话大脑）：OpenAI GPT-4o-mini / 通义千问 / 文心一言
  • 前端：LiveKit WebRTC SDK，浏览器直接通话
  • 部署：一台云服务器（2核4G即可）

这个Demo可以展示什么：

  • AI接听"电话"（实际是浏览器语音通话）
  • AI主动"外呼"（实际是浏览器推送通知+语音通话）
  • 口腔医院场景对话：预约、改约、问诊咨询、回访
  • 打断检测、多轮对话、知识库回答

阶段二：真实电话（需企业资质）

  1. 注册有限责任公司（非自然人独资） — 费用约500-2000元，1-2周
  2. 完成阿里云/腾讯云企业实名认证 — 1-3个工作日
  3. 申请语音服务资质 — 提交企业资质+话术审核，3-7个工作日
  4. 购买电话号码和线路 — 选择固话号或95/400号码
  5. 对接AI语音能力 — 用 LiveKit/Vocode + 云通信平台 SIP/API
  6. 上线测试 — 小规模外呼测试，验证话术合规
阶段二平台选择建议

首选：阿里云语音服务 — 文档最完善，API最稳定，生态最好。价格约0.08-0.15元/分钟。

备选：容联云通讯 — 对个人转企业最友好，认证快，支持SIP trunk。

讯飞作为语音引擎补充 — 中文ASR/TTS质量最好，可以作为语音能力层，线路另接。

Day 5-7
（可选）国际 SIP 号码测试
注册 Voip.ms，购买一个国际号码，通过 SIP trunk 接入 LiveKit/FreeSWITCH，测试真实的电话呼入/呼出。注意：对方看到的是境外号码。
Week 2
注册公司 + 提交企业认证
找代办注册有限责任公司，拿到营业执照后完成阿里云/腾讯云企业实名认证。
Week 3
申请语音服务资质 + 购买号码
提交话术审核（口腔医院预约提醒、回访等场景），购买电话号码。
Week 4
