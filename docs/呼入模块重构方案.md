# 呼入模块重构方案

## 一、需求概述

### 1.1 业务场景
口腔医院需要接入阿里云 CCC（云联络中心）的呼入功能，让客户可以拨打医院电话，由坐席在自己的系统中接听。

### 1.2 核心需求
| 序号 | 需求 | 说明 |
|------|------|------|
| 1 | SDK 接入 | 使用 WorkbenchSdk，不使用 CCC 工作台 |
| 2 | 来电弹屏 | 来电时显示客户信息（姓名、历史通话次数等） |
| 3 | 手动接听 | 坐席手动点击接听按钮 |
| 4 | 通话保持 | 支持通话保持和取回 |
| 5 | 话后处理 | 通话结束后进入话后处理状态（默认15秒） |

### 1.3 不需要的功能
- ❌ IM 聊天功能
- ❌ 转接功能（暂不实现）
- ❌ 会议功能（暂不实现）
- ❌ 监听/强插功能

onErrorNotify(error) {
  // error 结构:
  // {
  //   errorCode: 7001,

  //   errorMsgTip: '已有设备注册，软电话未初始化',

  switch (errorCode) {

      showToast('检测到其他设备在线，正在接管...', 'warning');

    case 8002:

### 4.2 业务逻辑

#### 4.2.1 通话事件处理

```python
# 事件类型处理逻辑
EVENT_HANDLERS = {
    'call_coming': handle_call_coming,      # 创建通话记录（振铃中）
    'call_establish': handle_call_establish, # 更新为已接通
    'call_release': handle_call_release,     # 更新为已完成
}

def handle_call_coming(call_detail):
    """
    来电振铃处理:
    1. 根据来电号码查找客户
    2. 如果客户不存在，自动创建
    3. 创建通话记录（状态: ringing）
    """
    caller = call_detail['caller']
    
    # 查找或创建客户
    customer = db.query(Customer).filter(Customer.phone == caller).first()
    if not customer:
        customer = Customer(
            id=str(uuid.uuid4()),
            name=f"客户{caller[-4:]}",
            phone=caller,
            notes="自动创建（来自来电）"
        )
        db.add(customer)
        db.commit()
    
    # 创建通话记录
    record = CallRecord(
        id=str(uuid.uuid4()),
        customer_id=customer.id,
        direction='inbound',
        caller_number=caller,
        callee_number=SYSTEM_DID,
        call_id=call_detail['call_id'],
        status='ringing',
        started_at=datetime.now()
    )
    db.add(record)
    db.commit()

def handle_call_establish(call_detail):
    """通话接通处理: 更新状态为 answered"""
    call_id = call_detail['call_id']
    record = db.query(CallRecord).filter(CallRecord.call_id == call_id).first()
    if record:
        record.status = 'answered'
        record.started_at = datetime.now()
        db.commit()

def handle_call_release(call_detail):
    """通话结束处理: 更新状态为 completed，记录时长"""
    call_id = call_detail['call_id']
    record = db.query(CallRecord).filter(CallRecord.call_id == call_id).first()
    if record:
        record.status = 'completed'
        record.duration = call_detail.get('duration', 0)
        record.ended_at = datetime.now()
        db.commit()
```

#### 4.2.2 客户信息查询

```python
@router.get("/customer-info")
async def get_customer_info(phone: str, db: Session = Depends(get_db)):
    """
    根据来电号码查询客户信息
    
    返回:
    - 客户基本信息（姓名、电话）
    - 历史通话次数
    - 最近通话时间
    """
    customer = db.query(Customer).filter(Customer.phone == phone).first()
    
    if not customer:
        return {"success": True, "customer": None}
    
    # 统计历史通话
    call_count = db.query(CallRecord).filter(
        CallRecord.customer_id == customer.id
    ).count()
    
    # 最近通话时间
    last_call = db.query(CallRecord).filter(
        CallRecord.customer_id == customer.id
    ).order_by(CallRecord.started_at.desc()).first()
    
    return {
        "success": True,
        "customer": {
            "id": customer.id,
            "name": customer.name,
            "phone": customer.phone,
            "call_count": call_count,
            "last_call_time": last_call.started_at.isoformat() if last_call else None,
            "notes": customer.notes
        }
    }
```

## 五、数据库表结构

### 5.1 现有表结构（无需修改）

```sql
-- 客户表
CREATE TABLE customers (
    id VARCHAR(36) PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    phone VARCHAR(20) UNIQUE NOT NULL,
    notes TEXT,
    created_at DATETIME,
    updated_at DATETIME
);

-- 通话记录表
CREATE TABLE call_records (
    id VARCHAR(36) PRIMARY KEY,
    customer_id VARCHAR(36) REFERENCES customers(id),
    direction VARCHAR(20),           -- inbound / outbound
    caller_number VARCHAR(30),       -- 主叫号码
    callee_number VARCHAR(30),       -- 被叫号码
    call_id VARCHAR(100),            -- CCC 通话ID
    contact_id VARCHAR(100),         -- CCC 通道ID
    status VARCHAR(50),              -- ringing / answered / completed / failed
    duration INTEGER DEFAULT 0,      -- 通话时长（秒）
    recording_url TEXT,              -- 录音URL（暂不使用）
    started_at DATETIME,
    ended_at DATETIME,
    created_at DATETIME,
    updated_at DATETIME
);
```

### 5.2 数据流

```
来电振铃 → 创建/查找客户 → 创建通话记录(ringing)
                              ↓
通话接通 → 更新通话记录(answered)
                              ↓
通话结束 → 更新通话记录(completed, duration, ended_at)
```

## 十、注意事项

### 10.1 SDK 使用注意

1. **资源加载顺序**：agentbar-sdk 必须在 workbenchSdk 之前加载
2. **HTTPS 要求**：页面必须使用 HTTPS（Chrome 限制）
3. **浏览器要求**：Chrome 58+
4. **麦克风权限**：iframe 需要添加 `allow="microphone"` 属性

### 10.2 钩子函数注意

1. **onBeforeCallDialing**：必须调用 `payload.callback()` 才能继续拨号
2. **onBeforeCallHangup**：必须调用 `payload.callback()` 才能挂断
3. **onInit**：SDK 初始化完成后才能调用 register()
4. **onRegister**：SIP 注册成功后才能调用 logIn()

### 10.3 状态管理注意

1. **状态码 6（振铃）**：此时只能调用 answer() 或 hangUp()
2. **状态码 9/10（通话中）**：可以调用 callHold()、muteAgent() 等
3. **状态码 5（话后处理）**：等待 afterCallRule 秒后自动回到空闲

### 10.4 不使用 IM

根据用户要求，本方案**不使用 IM 功能**：
- 不加载 IM SDK 资源
- 不配置 imConfig
- 不调用 renderIM() / unmountIM()

### B. 关键 SDK 方法

| 方法 | 说明 | 调用时机 |
|------|------|----------|
| register() | 首次注册（SIP + 登录） | onInit 后 |
| logIn() | 登录/上线 | onRegister 后，或离线状态 |
| logOut() | 登出/下线 | 需要下线时 |
| ready() | 置空闲 | 小休/话后处理后 |
| answer() | 接听来电 | 状态 6（振铃）时 |
| hangUp() | 挂断通话 | 通话中 |
| callHold() | 通话保持 | 通话中 |
| callRetrieve() | 通话取回 | 保持后 |
| muteAgent() | 静音 | 通话中 |
| unMuteAgent() | 取消静音 | 静音后 |
| forceToPrepareSignIn() | 强制注册（踢掉旧设备） | 收到 7001 错误时 |
